☁️ Sincronização via Internet Gratuita (Supabase + GitHub Pages) Redes Diferentes (Internet)

Ideal quando o seu computador e o aparelho Aquarius STV-Plus NÃO estão no mesmo Wi-Fi. Você abre o painel pelo link gratuito do GitHub Pages (de casa, do celular ou do escritório), publica um recado ou cartela, o painel grava no Supabase Gratuito e o Aquarius STV-Plus no elevador baixa automaticamente pela internet!

📋 Passo a Passo Rápido (100% Gratuito):
1. Crie uma conta gratuita em supabase.com → New Project → abra o menu SQL Editor e cole o conteúdo do arquivo supabase_setup.sql (que está na pasta do projeto) e clique em Run.
2. No Supabase, vá em Project Settings → API, copie a Project URL e a chave anon public e cole nos campos acima.
3. Suba esta pasta para um repositório no GitHub e ative o GitHub Pages (o workflow automático .github/workflows/deploy-pages.yml já publica o painel e o APK gratuitamente!).

Configurações Gerais do Sistema Vida Moderna News

📱 Como Instalar no Aparelho Aquarius STV-Plus (Mesmo em Redes Diferentes)

O aplicativo Android VidaModernaNews.apk sincroniza direto pela internet com o Supabase e o GitHub Pages:

  1. Opção A — Já embutir sua chave no APK antes de instalar: Edite o arquivo public/js/cloud-config.js com sua Supabase URL e Anon Key e clique duas vezes em gerar_apk.ps1. O VidaModernaNews.apk já nascerá configurado para o seu banco na nuvem!
  2. Opção B — Configurar direto na tela do Aquarius STV-Plus: Com o APK instalado no aparelho, clique na logo Modern Life Residence no canto inferior direito (ou aperte Menu no controle remoto) e cole a URL e a chave do Supabase uma única vez.
